<h1 align="center">Haven Craft</h1>

<p align="center"><em>We prioritize elegance.</em></p>

Haven Craft is a landing page for a curated wallpaper studio — quiet type, generous space, and collections made for people who care how their screen feels.

It is a static site: HTML, CSS, and a little JavaScript. No build step.

## What’s on the page

- **Hero** — phone mockups beside the line *We prioritize elegance*, with magnetic Telegram and Instagram icons
- **Collections** — Amoled, Scenery, Desktop, and Minimalism, each with a Get Now / BMC link
- **Phone showcase** — a pinned scroll sequence through Space, Scenery, Minimalist, and Material
- **.PNG app** — a promo for the .PNG that carries the full BMC library ([project page](https://maxx4688.github.io/portfolio/projects/dotpng.html))
- **Contact** — Formspree form
- **Footer** — Me and socials

Wallpapers live on the [BMC / Telegram page](https://t.me/maxxcraft). Support: [Buy Me a Coffee](https://buymeacoffee.com/maxx4688).

## Run it locally

Open `index.html` in a browser, or from this folder:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Built with

- [Playfair Display](https://fonts.google.com/specimen/Playfair+Display)
- [Lenis](https://github.com/darkroomengineering/lenis) for smooth scroll
- [GSAP](https://gsap.com/) + ScrollTrigger for the phone sequence and section motion
- [Formspree](https://formspree.io/) for messages
